=========================================================
🦷 치과 방사선 사진 AI 자동 정렬 프로그램 V2.1.1 사용 설명서 🦷
=========================================================

안녕하세요! 매번 실습이 끝나고 수십 장의 방사선 사진들을 일일이 회전시키고 이름을 바꾸며 분류하느라 고생이 많으시죠?
이 프로그램은 그 귀찮은 단순 반복 작업을 버튼 한 번으로 끝내기 위해 만들어졌습니다.

---------------------------------------------------------
💡 1. 개요: 이 프로그램은 어떻게 작동하나요? (V2.1.1 업데이트)
---------------------------------------------------------
이 프로그램 안에는 수많은 방사선 사진을 미리 보고 학습한 '인공지능(AI) 조수'가 들어있습니다.

실습 후 촬영한 원본 사진 폴더를 이 프로그램에 불러오면 다음과 같이 작동합니다.
1. AI가 사진을 분석하여 "상악 제1대구치 근원심 방향" 등 치식을 스스로 판단합니다.
2. [V2.1 🚀] 어떤 각도로 삐딱하게 찍혔든, AI가 치아 모양을 파악하여 **치관이 올바른 방향(상악은 아래, 하악은 위)을 향하도록 알아서 자동 회전**시킵니다!
3. 실습 제출 양식에 맞게 화면에서부터 미리 약어(nt, 상소 등)로 변환하여 띄워주며, 추가 메모(iaf 등)를 넣을 수 있는 4번째 칸을 제공합니다.
4. 조원별로 개인 폴더를 만들어서 결과물을 깔끔하게 정리해 줍니다.

---------------------------------------------------------
📦 2. 폴더 내 파일 목록 (절대 삭제하거나 위치를 바꾸지 마세요!)
---------------------------------------------------------
이 프로그램이 정상적으로 작동하려면 아래 파일과 폴더들이 **반드시 같은 폴더 안**에 모여있어야 합니다.

- main.exe : 프로그램 실행 파일 (이 파일만 더블클릭하시면 됩니다)
- _internal 폴더 : 프로그램 구동에 필요한 핵심 부품 폴더 (절대 지우거나 안의 내용을 건드리지 마세요!)
- students.xlsx : 실습 조 명단을 적어두는 엑셀 파일
- dental_model_v2.pth : 인공지능의 '뇌' (V2.1 전용으로 업데이트된 가중치 파일)
- class_names.txt : 인공지능의 정답지 목록 파일
- naming_rules.txt : 제출용 파일명 약어 규칙 (예: 자연치 -> nt)

---------------------------------------------------------
🛠️ 3. 사용 전 준비사항 (최초 1회만)
---------------------------------------------------------
1. 다운로드 받으신 ZIP 파일의 **압축을 반드시 풀어주세요!** (압축된 상태에서 exe를 바로 실행하면 에러가 발생합니다)
2. 폴더 안의 [students.xlsx] 파일을 열어서, 본인 조의 이름과 조원들의 교번, 이름을 알맞게 수정하고 저장해 주세요.
   (*주의: V2.1부터는 엑셀 첫 줄(1행)에 조, 교번, 조원 이름 행머리가 시작되어야 합니다!*)

---------------------------------------------------------
🚀 4. 실제 사용 방법 (Step by Step)
---------------------------------------------------------
[Step 1] 프로그램 켜기
- `main.exe`를 더블클릭해서 실행합니다. (최초 실행 시 구동을 위해 10~20초 정도 소요될 수 있습니다)
- 윈도우에서 "PC 보호" 경고가 뜨면 -> [추가 정보]를 누르고 -> [실행]을 클릭하시면 됩니다.

[Step 2] 실습 범위 세팅하기
- 화면 맨 위 [실습 치아 선택]에서 오늘 실습한 치아 종류를 모두 체크해 주세요.
- AI가 체크된 범위 안에서만 정답을 추론하기 때문에 정확도가 크게 올라갑니다!

[Step 3] 🙋‍♂️ 우리 조 세팅하기 & 순서 맞추기 (중요!)
- [조 선택]에서 해당 조를 고르면 엑셀 명단 순서대로 학생 카드가 나타납니다. (이름 위에 교번이 함께 표시됩니다.)
- **[V2.1.1 🚀 드래그 순서 변경]** 사진을 촬영한 순서와 엑셀 명단 순서가 다를 경우, **마우스로 학생의 이름 카드를 잡고 끌어서(드래그 앤 드롭) 사진이 찍힌 순서대로 자유롭게 배치**해 주세요!
- 조원들의 사진 개수가 다르다면 상단의 **[사진수 일괄변경]** 칸에 숫자를 넣고 '적용'을 눌러 한 번에 맞출 수 있습니다. 개별 변경도 가능합니다.

[Step 4] 사진 불러오고 확인하기
- [촬영사진 폴더 열기 & 자동 분류] 버튼을 클릭하고 원본 사진 폴더를 선택합니다.
- 사진이 큼직하게 띄워지며, 조원별로 가로 스크롤을 넘기며 확인할 수 있습니다. 
- 💡 **사진을 마우스로 클릭하면 원본 크기로 크게 확대**해서 볼 수 있습니다!

[Step 5] 🚨 최종 확인 및 보정 (가장 중요! 반!드!시! 확인) 🚨
- **AI는 완벽하지 않습니다! 치아 분류나 회전이 틀릴 수 있습니다.**
- **반!드!시!** 가로 스크롤을 넘기며 AI의 분류 결과와 회전 상태를 꼼꼼하게 눈으로 확인해 주세요.
- 틀린 부분이 있다면 글자 입력칸을 클릭해서 직접 고쳐 써주시고, 사진이 뒤집혀 있다면 [90°], [180°], [반전] 버튼을 눌러 올바르게 수정해야 합니다. 

[Step 6] 결과 저장
- 특정 사진에 모두 '초진, iaf, maf' 같은 메모를 붙여야 한다면, 우측 상단의 **[4번째 칸 일괄입력]**에 적고 '적용'을 누르세요.
- 최종 확인이 끝났다면 가장 우측의 **[결과 저장]**을 누릅니다. 
- 원본 사진 폴더 안에 '우리 조 이름'으로 된 새 폴더가 생기고, 조원별로 변환된 최종 사진들이 저장됩니다. (원본은 훼손되지 않습니다.)

---------------------------------------------------------
🍯 5. 꿀팁 및 주의사항
---------------------------------------------------------
- **단축어 변환 규칙을 바꾸고 싶으신가요?**
  `naming_rules.txt` 파일을 메모장으로 열어서 '자연치=nt' 부분을 원하시는 약어로 수정하고 저장하시면, 다음 실행 시 자동 적용됩니다.

- **여러분의 꼼꼼한 확인이 후배들을 위한 자산이 됩니다!**
  틀린 정답을 올바르게 고쳐주시고 '결과 저장'을 누르실 때마다, [Collected_Dataset] 폴더에 정답별로 분류된 사진이 자동으로 수집됩니다.
  이 데이터가 쌓이면 내년에는 훨씬 더 똑똑해진 AI를 후배들에게 물려줄 수 있습니다!
  그러니 제출 전 눈으로 꼼꼼한 확인을 다시 한번 부탁드립니다 😉
