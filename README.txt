=========================================================
🦷 치과 방사선 사진 AI 자동 정렬 프로그램 사용 설명서 🦷
=========================================================

안녕하세요! 매번 실습이 끝나고 수십 장의 방사선 사진들을 일일이 회전시키고 
이름을 바꾸며 분류하느라 고생이 많으시죠? 
이 프로그램은 그 귀찮은 단순 반복 작업을 버튼 한 번으로 끝내기 위해 만들어졌습니다.

---------------------------------------------------------
💡 1. 개요: 이 프로그램은 어떻게 작동하나요? (원리 안내)
---------------------------------------------------------
이 프로그램 안에는 수많은 방사선 사진을 미리 보고 학습한 
'인공지능(AI) 조수'가 들어있습니다. 

실습 후 촬영한 뒤죽박죽 원본 사진 폴더를 이 프로그램에 불러오면 다음과 같이 작동합니다.
1. AI가 사진을 분석하여 "아, 이건 상악 제1대구치 근원심 방향이네!" 하고 스스로 판단합니다.
2. 상악(위턱) 사진은 자동으로 180도 회전시켜 치관이 아래로 가게 해줍니다.
3. 실습 제출 양식(예: 80_홍길동_nt상대(1) 근원심.jpg)에 맞게 알아서 약어로 이름을 바꿉니다.
4. 조원별로 개인 폴더를 만들어서 결과물을 깔끔하게 정리해 줍니다.

사용자께서는 AI가 잘 분류했는지 눈으로 가볍게 확인하시고 '저장'만 누르시면 됩니다!


---------------------------------------------------------
📦 2. 폴더 내 파일 목록 (절대 삭제하거나 위치를 바꾸지 마세요!)
---------------------------------------------------------
이 프로그램이 정상적으로 작동하려면 아래 5개의 파일이 **반드시 같은 폴더 안**에 모여있어야 합니다.

- main.exe : 프로그램 실행 파일 (이 파일만 더블클릭하시면 됩니다)
- students.xlsx : 실습 조 명단을 적어두는 엑셀 파일
- dental_model.pth : 인공지능의 '뇌' (학습된 모델 가중치 파일)
- class_names.txt : 인공지능의 정답지 목록 파일
- naming_rules.txt : 제출용 파일명 약어 규칙 (예: 자연치 -> nt)


---------------------------------------------------------
🛠️ 3. 사용 전 준비사항 (최초 1회만)
---------------------------------------------------------
1. 다운로드 받으신 ZIP 파일의 **압축을 반드시 풀어주세요!** 
   (압축된 상태에서 exe를 바로 실행하면 에러가 발생합니다)
2. 폴더 안의 [students.xlsx] 파일을 열어서, 본인 조의 이름과 조원들의 
   교번, 이름을 알맞게 수정하고 저장해 주세요.


---------------------------------------------------------
🚀 4. 실제 사용 방법 (Step by Step)
---------------------------------------------------------
[Step 1] 프로그램 켜기
- `main.exe`를 더블클릭해서 실행합니다. (최초 실행 시 구동을 위해 10~20초 정도 소요될 수 있습니다)
- 윈도우에서 "PC 보호" 경고가 뜨면 -> [추가 정보]를 누르고 -> [실행]을 클릭하시면 됩니다.

[Step 2] 실습 범위 세팅하기
- 화면 맨 위 [실습 치아 선택]에서 오늘 실습한 치아 종류를 모두 체크해 주세요.
  (AI가 체크된 범위 안에서만 정답을 추론하기 때문에 정확도가 크게 올라갑니다!)

[Step 3] 우리 조 세팅하기
- [조 선택]에서 해당 조를 고르면, 엑셀에 적어둔 조원 이름이 나타납니다.
- 조원 이름 아래에 오늘 각자 촬영한 '사진 개수'를 숫자로 적어주세요. (기본 6장으로 설정되어있음.)

[Step 4] 사진 불러오고 자동 분류하기
- [촬영사진 폴더 열기 & 자동 분류] 초록색 버튼을 클릭합니다.
- 오늘 촬영한 원본 방사선 사진들이 한번에 모여있는 폴더를 선택합니다.
- AI가 사진을 저장한 순서대로 학생별 개수에 맞게 나누고, 추론 결과를 화면에 띄워줍니다.

[Step 5] 최종 확인 및 보정 (가장 중요!)
- AI가 100% 완벽하진 않을 수 있습니다. 스크롤을 내리며 AI의 분류 결과를 확인해 주세요.
- 틀린 부분이 있다면? 글자 입력칸을 클릭해서 올바른 정답으로 직접 고쳐 써주시면 됩니다!
(각 치아의 이름은 [실습 치아 선택]에 적힌 이름으로 수정해주셔야 정상적인 약어로 수정됩니다!)
- 사진이 뒤집혀 있다면 사진 아래의 [↻(180도 회전)] 또는 [↔(좌우 반전)] 버튼을 눌러주세요.

[Step 6] 결과 저장
- 모두 알맞게 확인되었다면 우측 상단의 [결과 저장] 파란색 버튼을 눌러주세요.
- 촬영한 원본 사진 폴더 안에 '우리 조 이름'으로 된 새 폴더가 생기고, 
  그 안에 조원별 폴더 및 이름이 변환된 최종 사진들이 깔끔하게 저장됩니다.
  (원본 사진은 절대 삭제되거나 훼손되지 않으니 안심하세요!)


---------------------------------------------------------
🍯 5. 꿀팁 및 주의사항
---------------------------------------------------------
- **단축어 변환 규칙을 바꾸고 싶으신가요?**
  `naming_rules.txt` 파일을 메모장으로 열어서 '자연치=nt' 부분을 
  원하시는 약어로 수정하고 저장하시면, 다음 실행 시 자동 적용됩니다.

- **여러분의 꼼꼼한 확인이 후배들을 위한 자산이 됩니다! (데이터 수집)**
  Step 5에서 틀린 정답을 올바르게 고쳐주시고 '결과 저장'을 누르실 때마다, 
  [Collected_Dataset] 이라는 폴더에 정답별로 분류된 사진이 자동으로 수집됩니다. 
  이 데이터가 쌓이면 내년, 내후년에는 훨씬 더 똑똑해진 AI를 후배들에게 물려줄 수 있습니다! 
  그러니 제출 전 눈으로 꼼꼼한 확인 부탁드립니다 😉
  용량이 부족하시다면 삭제하셔도 무방합니다.
